YouTube: Clear Watch Later

Empties your YouTube Watch Later playlist in about a minute instead of three clicks per video. It removes up to 500 videos per request, oldest-added first, and keeps a list of everything it removed so you can download it.

Version1.0.0
Permissionsstorage only
Runs onwww.youtube.com, HTTPS, top frame
Networkwww.youtube.com only, after you confirm

Why this is fast

YouTube has no "remove all" for Watch Later. Its only bulk option is Remove watched videos, which leaves everything you never started. By hand it is ⋮ → Remove from Watch later for every video.

That menu item sends one request to YouTube's own web API, POST /youtubei/v1/browse/edit_playlist, with a list of actions. The page only ever puts one action in the list; the endpoint accepts many. Measured against a real 4,681-video Watch Later in November 2026:

The time barely moves with batch size, so the extension sends 500 at a time (the largest size tested). Listing is the slow part: YouTube returns the playlist 100 entries per request, so 4,681 videos took 46 requests and about 30 seconds. A full clear of that list is about a minute and a quarter.

How it works

  1. Count. Opening the popup makes one request for the first page and shows the playlist's video count.
  2. List. When you confirm, it pages through the whole playlist collecting each entry's id, video id and title, including unavailable (deleted or private) videos the page normally hides.
  3. Remove, oldest-added first, 500 per request. Stop half way and the newest videos are the ones left.
  4. Check again and make another pass if anything is left (up to three).
  5. Reload the tab if you're on the Watch Later page.

A rejected batch is split in half and retried down to single entries; rate limits and server errors are retried with backoff (2, 4, 8, 16 s) before it stops with an error.

Signing the requests

YouTube's API ignores your sign-in cookies unless the request also carries the Authorization: SAPISIDHASH … header YouTube's own page computes; without it, removals quietly do nothing. So the content script reads the SAPISID cookies with document.cookie inside the YouTube tab, at the moment it sends each request, and builds the same header: SAPISIDHASH <time>_<SHA-1 of "<time> <SAPISID> https://www.youtube.com">.

This is the one extension in the repo that reads cookies. The values are hashed and sent only to www.youtube.com, exactly as YouTube's page sends them, and are never stored, logged, shown or sent anywhere else. It is the price of doing this through the API instead of clicking through menus.

Using it

  • Clear Watch Later turns into Yes, remove all N for five seconds; click again to start. No browser dialog.
  • A progress bar shows the listing, then the removals. Stop finishes the current request and stops.
  • You can close the popup while it runs; the work happens in the YouTube tab. Closing or reloading the tab stops it.
  • Download list (CSV) saves url,title for every video it removed, across runs, so you can re-add anything you didn't mean to lose. Forget list deletes it.

What data it reads, stores or sends

  • Reads YouTube's inline ytcfg settings script and the SAPISID, __Secure-1PAPISID and __Secure-3PAPISID cookies; from the API, your Watch Later entries and count.
  • Network: only POST https://www.youtube.com/youtubei/v1/browse and …/browse/edit_playlist, only after you click. Nothing goes to any other server. No analytics, no telemetry.
  • Stores the removed-videos list (video id and title, up to 6,000) in chrome.storage.local until you forget it. No cookie or header value is ever stored.

What it does not do

  • Does not touch any playlist but Watch Later, and does not like, subscribe, comment or change settings.
  • Does nothing until you confirm; opening the popup makes one read-only request.
  • Does not keep or forward your cookies or the signed header.
  • Does not inject UI into YouTube or load code from anywhere.

Honest caveats

  • It uses YouTube's private web API, the same one its own page uses but undocumented. If YouTube changes it, the extension stops with an error rather than guessing; innertube.js is the file to update.
  • Removals can't be undone in bulk. The downloadable list is the safety net.
  • 500 per request is what was tested. The split-in-half fallback covers a rejected batch.
  • It acts as whichever account the tab is signed in as. Brand accounts should work but only a personal account was tested.
  • If you'd rather an extension never see your sign-in cookie, use YouTube's Remove watched videos and the ⋮ menu instead.

Security

Follows the repo's shared security guidelines (the OWASP Browser Extension Vulnerabilities Cheat Sheet): storage is the only permission, the content script runs HTTPS-only in the top frame, a strict CSP forbids remote code, no innerHTML or eval, popup↔page messaging checks sender.id and allows four message types, and the CSV export defuses spreadsheet formulas in titles. The API helpers have their own unit tests, and tests/owasp-audit.mjs enforces the static rules.

Install

  1. Download or clone the repo.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the chrome-extensions/youtube-clear-watch-later folder.
